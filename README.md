# fonarik

Минималистичный переключатель фонарика для Samsung Galaxy (One UI / Android 14–16).

При нажатии на иконку приложение мгновенно переключает фонарик и сразу закрывается — без окон, заставок, шторок и ожидания.

### Сценарий использования с Good Lock (RegiStar)
Приложение идеально подходит для привязки к жестам в **Good Lock -> RegiStar** (двойной/тройной тап по задней крышке или действие на кнопку питания):
1. В модуле RegiStar выбираем: **Back-Tap action** (или **Side-Key press and hold action**) -> **Open app** -> **Фонарик**.
2. Теперь по двойному постукиванию по задней крышке смартфона фонарик мгновенно включается на максимальную яркость One UI или выключается — абсолютно незаметно, без всплывающих окон и прерывания работы на экране.

## Особенности

- **Zero-UI**: запускается с `@android:style/Theme.NoDisplay`, отключает системные анимации и вызывает `finish()` в `onCreate()`. Окно не появляется, в списке недавних приложений не висит (`noHistory`, `excludeFromRecents`).
- **Аппаратная синхронизация**: считывает реальное состояние вспышки через `CameraManager.TorchCallback`. Если фонарик включили из шторки Samsung — тап по иконке выключит его, и наоборот.
- **Максимальная яркость Samsung**: использует `turnOnTorchWithStrengthLevel(cameraId, 5)` для активации 5-го (максимального) уровня яркости вспышки в One UI.
- **Тактильный клик**: подтверждает срабатывание коротким системным виброоткликом (`VibrationEffect.EFFECT_CLICK`).
- **Размер**: APK весит 25 КБ. Никаких сторонних зависимостей, рекламы, сервисов и разрешений на доступ в интернет.

## Установка

1. Скачайте `fonarik.apk` из [Releases](../../releases) (или из репозитория).
2. Установите на телефон через проводник или ADB:
   ```bash
   adb install -r fonarik.apk
   ```

## Сборка

Для сборки достаточно JDK 17+ (полный Android SDK не требуется, все необходимые тулзы подтягиваются скриптом):

```powershell
.\build_apk.ps1
```

Скрипт компилирует Java-код, конвертирует его в DEX, линкует ресурсы через `aapt2` и подписывает схемами v1, v2 и v3 (`apksig`).
